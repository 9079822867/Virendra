## Database Integration

**Database**: VRECHARGEDB
**Table**: [User]
**Key Fields Used**:
- Username (login identifier)
- Password (credentials)
- IsActive, IsLocked, IsDeleted (status)
- RetryCount (failed attempts)
- LoginIP (audit trail)

## Quick Start (3 Steps)

### Step 1: Install Dapper
```powershell
Install-Package Dapper
```

### Step 2: Update Web.config
```xml
<connectionStrings>
  <add name="DefaultConnection" 
       connectionString="Server=YOUR_SERVER;Database=VRECHARGEDB;User Id=sa;Password=YOUR_PASSWORD;" 
       providerName="System.Data.SqlClient" />
</connectionStrings>
```

### Step 3: Test
- URL: `http://localhost/Auth/Login`
- Create a test user in database
- Login with credentials

## Login Flow

```
User → Login Page
      ↓
   Enter Username/Password
      ↓
   Validate Input
      ↓
   Query User from DB (Dapper)
      ↓
   Check Status (Active, Not Locked, Not Deleted)
      ↓
   Verify Password
      ↓
   If Success:
     - Set Auth Cookie
     - Reset RetryCount
     - Update LoginIP
     - Redirect to Dashboard
      ↓
   If Failed:
     - Increment RetryCount
     - Check if >= 5 attempts
     - If yes: Lock Account
     - Show error with remaining attempts
```
